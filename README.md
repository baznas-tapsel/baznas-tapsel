# BAZNAS Kabupaten Tapanuli Selatan — Website & Buletin

Situs resmi dan buletin BAZNAS Kabupaten Tapanuli Selatan.
Seluruh halaman ada di satu file: `index.html` (HTML5 + Tailwind CSS via CDN).

## Cara mengubah isi
Buka `index.html`, lalu cari blok komentar section, misalnya:
- `<!-- HERO SECTION -->`
- `<!-- BULETIN SECTION -->`
- `<!-- REKENING RESMI SECTION -->`

Ubah teks di antara komentar START dan END. Setiap perubahan di branch `main` akan diterbitkan otomatis oleh Vercel.
